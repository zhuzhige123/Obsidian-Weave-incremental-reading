# 添加阅读点

日常新增**一条**阅读点，请用「添加链接 / 添加阅读目标」，而不是材料导入。

- **添加**：一条 URL、一个双链或块、一个选区、一个 Canvas 节点、一个 EPUB 定位  
- **导入**：整份 Markdown / PDF 目录 / EPUB 目录 → 批量生成大量阅读点（见 [材料导入与订阅](import-and-subscription.md)）

## 推荐入口

| 入口 | 说明 |
|------|------|
| 日历顶部 **「+」/ 添加链接** | 日常主路径 |
| 命令面板 **添加阅读目标到增量阅读** | 与模态窗同一流程 |

## 模态窗五步

1. **粘贴链接**，或点击 **「当前位置」** 捕获 Markdown 编辑器中的块 / 行锚点  
2. **确认阅读点名称**  
3. **选择归属专题**（`.irdeck`；可新建）  
4. **安排首次阅读日**（自选日期或系统推荐）  
5. **可选**：创建阅读笔记、在源笔记追加标记 → 确认后写入队列并排期

完成后，阅读点会出现在对应日期的日历列表中，打开即可回跳原文。

## 支持粘贴的类型

```text
网页：          https://…
Vault / 块：    [[笔记]]、[[笔记#^块ID]]
PDF++：         选区或书签链接（callout 内的 PDF 链接亦可）
Canvas：        [[画布.canvas#^nodeId]]
EPUB：          定位链接（需安装并启用 Weave EPUB Reader）
```

**示例（Markdown 块）：**

```markdown
- 待读：[[研究方法#^a1b2c3]]
```

将 `[[研究方法#^a1b2c3]]` 粘贴进「添加链接」，命名后选专题与日期即可。

**示例（网页）：**

```text
https://example.com/article
```

网页型阅读点通常会创建摘录笔记载体，便于在库内留下可链对象；回跳时用 Obsidian 浏览器打开该 URL。

## 其它快捷入口

| 场景 | 操作 |
|------|------|
| Markdown 选区 | 命令 **从当前选区创建增量阅读点** |
| Obsidian 浏览器 | 网页菜单 / 选区右键 → **添加到增量阅读** |
| Canvas 节点 | 节点菜单 → **添加到增量阅读** |
| 当前网页 | 相关命令 **从当前网页添加到增量阅读**（若可用） |

快捷入口最终仍进入同一套「命名 → 专题 → 首次排期」逻辑，只是来源预填不同。

## 与专题、默认收件箱

设置中可为**新增阅读点**配置默认专题（收件箱）等选项，减少每次手工选择。详见 [设置](settings.md)。

建议：长期计划用稳定专题名；临时剪藏可进收件箱专题，再定期整理到正式专题。

## 最佳实践

1. **能粘贴稳定定位就粘贴**（块 ID、PDF++ 选区、Canvas 节点 ID），少用「只有文件名、没有位置」的模糊链接  
2. **一条阅读点只表达一件待读任务**；长文需要拆分时用导入或多次添加，再用 [连续阅读](calendar.md#连续阅读)  
3. **首次阅读日如实选择**；「全部丢到今天」会迅速抬高当日负载  
4. EPUB / 精确 PDF 选区分别依赖 **Weave EPUB Reader** / **PDF++**——未安装时仍可能添加，但回跳体验会变弱
