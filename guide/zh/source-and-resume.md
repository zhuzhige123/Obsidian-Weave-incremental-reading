# 来源与续读

每个阅读点保存稳定的**续读链接**与**来源类型**。从日历打开时，插件按类型路由回原文，并尽可能定位到创建时的位置。

## 溯源原则

1. 创建时尽量带上**可定位**信息（块 ID、页码选区、节点 ID、CFI 等）  
2. 回跳依赖对应能力或协作插件是否可用  
3. 源文件移动/重命名可能导致「来源丢失」——此时需修复链接或重建阅读点  

## 按类型说明

### Obsidian Markdown

| | |
|--|--|
| **加入** | 块引用 `[[笔记#^块ID]]`、行锚点，或「当前位置」/ 选区快速创建 |
| **回跳** | 打开笔记并滚动到块或行，必要时显示定位高亮 |
| **依赖** | Obsidian 原生 Markdown |

可在设置中开启 **Markdown 聚焦阅读**：在任意笔记中按块弱化周围内容，便于专注（免费能力，详见 [设置](settings.md)）。

### PDF（PDF++）

| | |
|--|--|
| **加入** | 粘贴 PDF++ 选区 / 书签链接；或用导入按目录批量创建（高级） |
| **回跳** | 打开 PDF 并解析页码与选区锚点 |
| **依赖** | Obsidian PDF 能力；**精确选区**建议配合 [PDF++](https://github.com/RyotaUshio/obsidian-pdf-plus) |

### Canvas 节点

| | |
|--|--|
| **加入** | Canvas 节点菜单，或粘贴 `[[画布.canvas#^nodeId]]` |
| **回跳** | 打开对应 Canvas，按节点 ID 定位高亮（必要时辅以文本候选） |
| **依赖** | Obsidian 内置 Canvas |

### Obsidian 浏览器（网页）

| | |
|--|--|
| **加入** | Web Viewer「添加到增量阅读」，或粘贴 `https://…`；通常会创建阅读笔记载体 |
| **回跳** | 用 Obsidian 浏览器打开该 URL |
| **依赖** | Obsidian 内置网页查看器 |

若摘录笔记载体丢失，关联/菜单流程可能提示并允许重新创建（关联笔记为高级功能时，入口受授权影响）。

### Weave EPUB Reader

| | |
|--|--|
| **加入** | 阅读器中选中文本后「添加到增量阅读」，或粘贴 EPUB 定位链接；**高亮本身不会自动变成阅读点** |
| **回跳** | 通过 `obsidian://weave-epub-reader` 协议打开书籍并定位到 CFI / 章节 |
| **依赖** | [Weave EPUB Reader](weave-family.md) |

章节批量导入同样依赖 EPUB Reader 提供的目录能力（高级功能）。

## 关联笔记（高级，按类型分流）

入口：阅读点右键 / 长按 → **关联笔记**。

| 类型 | 行为 |
|------|------|
| **PDF / EPUB** | 精选关联：打开、追加、新建、设主笔记、移除等 |
| **Markdown / 网页** | 打开来源笔记，并浏览出链相关笔记；网页还可打开原链接 |

已关联或存在出链时，列表项上可能出现「笔记」徽章。未激活时入口可能隐藏或显示为带锁预览。

## 最佳实践

1. Markdown 优先打块 ID，再添加阅读点  
2. PDF 重要段落用 PDF++ 生成选区链接再添加  
3. EPUB 选区添加，而不是假设「高亮 = 已入队」  
4. 重命名/移动源文件后，若列表提示缺失来源，尽早修复
