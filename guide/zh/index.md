# Weave Incremental Reading 教程

**把「以后再看」变成可排期、可续读的阅读队列。**

本教程面向官网读者，说明当前版本里真实可用的功能与推荐用法。日常主路径是：**打开增量阅读日历 → 用「添加链接」收入材料 → 回跳原文续读 → 按调度推进**。

## 五分钟上手

1. 安装并启用 **Weave Incremental Reading**（Obsidian ≥ 1.8.7）
2. 打开 **增量阅读日历**（功能区日历图标，或命令「打开增量阅读日历」）
3. 点顶部 **「+」/ 添加链接**：粘贴来源 → 命名 → 选专题 → 安排首次阅读日 → 保存
4. 在今日列表打开条目，回跳原文续读；完成后标记进度，系统安排下次出现

更细的步骤见 [添加阅读点](add-reading-points.md) 与 [增量阅读日历](calendar.md)。
