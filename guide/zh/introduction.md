# 入门概览

Weave Incremental Reading 把散落在 Markdown、块引用、PDF、Canvas、网页、EPUB 等处的材料，整理成**可排期、可续读、可回跳**的阅读点，用专题与日历按节奏推进——而不是收藏即等于读过。

本插件是独立的增量阅读主控：**不依赖** Weave 主插件即可单独使用；需要时再与 Weave EPUB Reader、Weave 主插件组合。

## 三个核心概念

| 概念 | 说明 |
|------|------|
| **阅读点** | 一条待阅读任务，带来源溯源；可从队列一键回跳原文继续读。 |
| **专题（`.irdeck`）** | 阅读点的容器，以专题文件保存在知识库中，按主题或计划分组。 |
| **增量阅读日历** | 插件主界面：按日期查看待处理、已排期与逾期的阅读点，安排每日节奏。 |

**关键区别：**

- **阅读点**是调度与续读的最小单位
- **专题**负责分组与归属（一条阅读点同一时刻归属一个专题）
- **日历**是日常决策发生的地方：今天读什么、负载是否过重、逾期如何处理

## 核心能力一览

- **统一「添加链接」**：粘贴网页、双链、块引用、PDF++、Canvas 节点、EPUB 定位链接；一次完成命名、专题与首次排期
- **材料导入与订阅文件夹**：批量拆分 Markdown；高级功能支持 PDF / EPUB 章节导入与订阅文件夹自动补齐
- **调度与续读**：统一默认节奏、每日上限与负载平滑；完成后安排下次出现；打开即可回跳原文
- **连续阅读**：按同一来源展开相关阅读点，顺着一篇文档连续推进（免费）
- **关联笔记**（高级）：PDF / EPUB 精选关联；Markdown / 网页用来源笔记出链
- **来源回跳**：Markdown、PDF++、Canvas、网页、EPUB 等保留稳定续读位置

## 快速上手

1. 安装插件（Release / BRAT / 社区目录），在 **设置 → 社区插件** 中启用
2. 打开 **增量阅读日历**
3. 使用顶部 **「+」/ 添加链接** 创建第一条阅读点
4. 从今日列表打开并续读；标记进度后观察下次排期

日常新增请优先走 **添加链接**；整份文档或整书拆分再用 **导入阅读材料**。选区命令与右键菜单仍可用。

## 系统要求

| 项目 | 要求 |
|------|------|
| Obsidian | ≥ 1.8.7（以 `manifest.json` 的 `minAppVersion` 为准） |
| 平台 | 桌面端与移动端 |

## 免费功能与高级功能

当前版本：**增量阅读日历与 Markdown 阅读点主流程免费开放**，足以完成日常增量阅读。

| 免费 | 高级（需激活） |
|------|----------------|
| 日历与 Markdown 阅读点 | 批量导入 PDF / EPUB 章节阅读点 |
| 专题与阅读点管理（优先级、暂停、归档） | 负载与顺延、交错学习设置 |
| 基础调度、今日待读、续读回跳 | 订阅文件夹自动同步 |
| 添加链接（含 MD、块链接、PDF++ 等） | 统计分析、阅读计时器等 |
| 从 Markdown 拆分导入、数据管理工具 | 阅读点关联笔记等更多能力 |
| 连续阅读、Markdown 聚焦阅读 | 标签组（仍在完善中，勿作主流程依赖） |

未激活时，高级入口会明确提示或显示为带锁预览（可在设置中开启「高级功能预览」）；基础阅读流程不受影响。

若已安装并激活 **Weave 主插件**，本插件可继承其授权。独立激活：**设置 → Weave Incremental Reading → 授权**。

## 数据与隐私（摘要）

- 阅读点、专题、调度与设置默认保存在**本地知识库**
- 插件不会主动上传你的笔记内容
- 卸载插件不会自动删除已创建的 `.irdeck` 与阅读点数据

详见 [数据与维护](data-and-maintenance.md)。
