# 调度与进度

调度决定阅读点**何时再次出现在日历上**。它服务的是阅读节奏，**不是** Weave Review 的 FSRS 间隔复习。

基础调度（今日队列、完成后下次出现、优先级与暂停/归档等）在免费主流程中可用；**调度策略的深度自定义、交错学习**等属于高级功能。未激活时，请以实际设置中的锁定提示为准。

## 统一默认节奏

插件使用一套通用初始间隔（月历 **强化 / 正常 / 放缓** 约为 **1 / 3 / 7 天**），与完成推进共用同一公式。不再提供「处理流 / 阅读列表」二选一；升级后会自动迁到该默认。

之后节奏由：日历菜单与完成推进、设置中的时间预算 / 日上限 / 负载顺延等，以及算法自动计算共同决定。先跑通「添加 → 续读 → 安排」闭环，再按体感微调。

## 常见节奏控件（概念）

具体滑杆与开关以 **设置 → 调度 / 标签组** 为准，常见概念包括：

| 概念 | 作用（直观理解） |
|------|------------------|
| **每日时间预算** | 一天打算花多少分钟读书 |
| **每日阅读点上限** | 条数软顶，防止短文刷屏 |
| **心流 stretch** | 允许略超基线负载的弹性区 |
| **负载自动顺延** | 过载时在**计划视图**里往后挪（默认不改磁盘上的下次出现日） |
| **跨日平滑** | 计划视图避免某几天尖峰、其它天空窗（同上，默认不写回承诺 due） |
| **提前阅读窗口 / 间隔相关选项** | 控制可提前看到与再次出现的节奏 |

日负载摘要在日历侧常见类似提示：**合理负载 · 心流上限 · 已安排** 分钟数。

## 阅读点状态与操作

| 操作 | 含义 |
|------|------|
| **打开 / 续读** | 回跳原文 |
| **标记进度 / 完成推进** | 按统一公式与当前设置计算下次出现 |
| **改期 / 排期** | 手动指定或调整日期 |
| **优先级** | 影响队列中的相对重要性（界面常见 P 级；摘要导出等场景会区分高优先级） |
| **暂停（搁置）** | 暂时离开今日主队列；可在「继续阅读建议」中恢复到今天 |
| **归档** | 结束该阅读点的活跃调度；Markdown 源笔记可写入归档相关标签便于库内筛选（非 MD 源不受此影响） |
| **移除** | 从专题/队列中去掉（请确认后再操作） |

归档、搁置、恢复与移除走统一调度写入路径，列表应按规则立即更新。

## 连续阅读与父子关系

当同一来源被拆成多个阅读点时：

- 使用日历中的 **连续阅读** 按来源展开  
- 若存在父/子阅读点结构，可用来表达整体进度（以界面展示为准）  

详见 [增量阅读日历 · 连续阅读](calendar.md#连续阅读)。

## 订阅与「今天」钉选

从订阅文件夹入库时：

- **添加到今天** → 钉在今天  
- **按算法正常调度** → 按视野与负载均摊  

不要用「添加到今天」却期望系统自动摊到后面几天。详见 [材料导入与订阅](import-and-subscription.md)。

## 高级相关（可选）

| 能力 | 说明 |
|------|------|
| 负载与顺延 | 负载顺延、跨日平滑、超载缓冲、单日出现上限等（高级） |
| 交错学习 | 多材料交错推进相关设置（高级） |
| 阅读计时器 | 为阅读点记录时长（高级） |
| 统计分析 | 负荷预测与阅读分析视图（高级） |
| 标签组 | 按标签套不同调度偏好——**仍在完善中，勿作主流程依赖** |

## 最佳实践

1. 先跑通默认节奏，再微调数字  
2. 日上限与时间预算一起看：只加时间不够时再提高条数上限  
3. 逾期用改期或整理积压处理，而不是长期无视  
4. 需要记忆复习时使用 Weave 主插件，而不是在本插件里「模拟 Anki」
