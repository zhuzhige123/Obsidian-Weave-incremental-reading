# 排错

按症状查找。若仍无法解决，请到仓库 [Issues](https://github.com/zhuzhige123/Obsidian-Weave-incremental-reading/issues) 反馈，并注明 Obsidian 版本、插件版本与平台（桌面 / 手机）。

## 日历或列表异常

### 找不到增量阅读日历

- 命令面板搜索 **打开增量阅读日历**  
- 确认插件已启用  
- 旧版「主阅读界面」入口若仍存在，应已重定向到日历；请改用日历作为唯一主界面  

### 新建专题后搜索 / 目录里暂时没有

- 稍候或重开日历侧栏，索引会刷新  
- 确认 `.irdeck` 写在当前设置的数据根下的 `points/`（或等价路径）  
- 用数据管理工具检查专题是否可读  

### 归档 / 搁置后列表仍短暂显示

当前版本应立即按隐藏规则更新。若持续残留：

- 确认操作已成功（可再开一次菜单看状态）  
- 切换日期或重开日历  
- 仍异常时记录复现步骤并反馈  

### 手机上月历工具栏或列表滑动异常

请升级到包含移动端侧栏 / `nav-header` 相关修复的版本；并确认没有第三方主题严重覆盖 leaf 头部结构。

## 添加与导入

### 粘贴后无法识别链接

- 检查是否完整（`https://`、`[[...]]`、PDF++ 链接、`*.canvas#^nodeId`）  
- 同批导入是否混了 md/pdf/epub（不允许）  
- EPUB 定位是否在已启用 Weave EPUB Reader 的环境中产生  

### 导入的 PDF / EPUB 入口不可用

- 确认已激活高级功能，或开启「高级功能预览」查看带锁入口  
- EPUB 目录依赖 Weave EPUB Reader  

### 订阅不收录新文件

- 确认订阅的是 **Markdown** 文件夹  
- 规则是否绑定专题、是否启用  
- 手动执行 **更新订阅文件夹**  
- 未激活高级功能时订阅不可用  

### 「添加到今天」的材料出现在后面几天

- 检查该次入库用的是 **添加到今天** 还是 **按算法正常调度**  
- 只有后者会按视野天数均摊 due  

## 续读与来源

### 提示来源丢失 / 打不开原文

- 源文件是否移动、重命名或删除  
- PDF++ / EPUB 链接是否仍有效  
- Canvas 节点 ID 是否还在  
- Markdown 块 ID 是否被删掉  

### EPUB 回跳无效

- 安装并启用 **Weave EPUB Reader**  
- 确认阅读点保存的是定位链接，而不仅是书名  
- 高亮不会自动变成阅读点——需走「添加到增量阅读」  

### PDF 只能打开文件、到不了选区

- 安装并使用 **PDF++** 生成的选区 / 书签链接再添加  
- 仅有文件路径的阅读点无法提供精确选区  

## 调度与状态

### 完成后很久不再出现 / 出现过勤

- 查看设置中的间隔、日上限、时间预算与负载顺延等选项  

- 是否被暂停（搁置）或归档  
- 日上限与时间预算是否把新放出卡住  

### 以为在用 FSRS 但行为对不上

本插件调度不是 FSRS。间隔复习请使用 **Weave 主插件**。见 [设计理念](philosophy.md)。

### 标签组不生效

标签组仍在完善中，可能无法正常使用。请改用专题、优先级与基础调度。见插件内教程说明。

## 授权

### 高级功能带锁

- 在 **设置 → 授权** 激活，或确认主插件授权可继承  
- 可开启「高级功能预览」查看入口，但未激活仍不可用  

### 已买主插件仍提示未授权

- 确认主插件已激活且版本支持继承  
- 重载插件或重启 Obsidian 后再看本插件授权页  

## 数据

### 换机后专题消失

- 是否同步了数据根文件夹（默认 `weave Incremental reading/`）  
- 设置中的数据路径是否与实际文件夹一致  

### 仍有旧格式阅读点

- 使用 **数据管理** 做统一 / 迁移，不要继续按旧格式新建  
- 临时编辑文件若曾落在笔记旁，可删除；其后应落在数据根下的 `editor/` 等目录
