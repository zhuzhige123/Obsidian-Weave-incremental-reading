# 数据与维护

阅读点与专题的真相来源在 **Vault 数据**里；插件目录主要存设置与可重建的缓存。备份与同步时请优先保护 Vault 侧数据根与全部 `.irdeck` 文件。

## 两层存储

| 层 | 内容 | 备份优先级 |
|----|------|------------|
| **Vault 数据** | 专题、阅读点、材料与注册信息等 | 高——应纳入库备份 / 同步 |
| **插件目录** | `data.json` 设置、cache、state | 中——多数可重建；换机可不强求 cache 一致 |

## Vault 数据根

默认文件夹名为：

```text
weave Incremental reading/
```

可在 **设置 → 基础 → 数据文件夹** 中修改。其下直接存放业务数据，并与 Weave 系列其它插件常用的 `weave/` 目录隔离。

典型结构：

```text
weave Incremental reading/
  points/                  # .irdeck 专题文件
  materials/
  registry/
  pdf-bookmark-tasks.json
  epub-bookmark-tasks.json
  IR/                      # 兼容用导入目录
  editor/                  # 段落工作台等所需临时编辑文件（若产生）
```

`IR/` 为历史兼容路径；日常收录请走「添加链接」或「导入阅读材料」，不必手工维护该目录。

## `.irdeck` 专题文件

每个专题是一份 **`.irdeck`** 文件：包含专题元数据与 `points` 数组（调度、溯源、关联等）。

跨插件或外部工具协作时，应以 `.irdeck` 中的阅读点记录为**唯一真相**，避免只改旁路缓存或复制品。

在文件管理器中打开 `.irdeck`，可进入专题相关视图，并与日历联动。

## 插件目录

路径通常为：

```text
.obsidian/plugins/weave-incremental-reading/
```

| 路径 | 说明 |
|------|------|
| `data.json` | 插件设置 |
| `cache/`、`state/` | 本地加速与运行态 |

卸载插件**不会自动删除** Vault 内已创建的 `.irdeck` 与阅读点数据；清理请用数据管理工具或手动删除。

## 数据管理工具

入口：

- 设置 → 数据管理  
- 或日历 **更多 → 数据管理**（若提供）  

用于库内专题巡检、格式统一、重复处理、备份相关操作等。若仍存在旧版 Markdown 阅读点格式，请在此走**统一 / 迁移**流程，而不是在教程里继续以旧格式作为新建方式。

## 备份建议

1. 备份整个 Vault（或至少完整复制数据根文件夹，含全部 `.irdeck`）  
2. 更改数据根路径前，确认旧目录已复制到位且插件能枚举到专题  
3. 同步工具请避免只同步笔记、不同步数据根  
4. 授权信息与笔记内容无关；换机后按设置页重新激活或继承主插件授权  

## 隐私摘要

- 默认本地保存；插件不主动上传笔记正文  
- EPUB 回跳、授权校验等仅在对应功能实际使用时发生网络或跨插件调用
