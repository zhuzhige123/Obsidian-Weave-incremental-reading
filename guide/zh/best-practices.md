# 最佳实践

下列建议来自当前产品设计与插件内教程，帮助你把主路径跑稳，而不是堆功能。

## 1. 选定一条主路径

| 角色 | 日常怎么做 |
|------|------------|
| 新增一条 | 日历 **添加链接** |
| 整书 / 长文拆分 | **导入阅读材料** |
| 剪藏收件箱 | **订阅文件夹**（高级） |
| 每天开始 | 先打开 **增量阅读日历** |

避免把实验性段落工作台或任何已移除的旧主阅读界面当作默认入口。

## 2. 专题命名保持稳定

同一计划始终使用同一专题名（同一 `.irdeck`）。

**推荐：** `网站改版`、`Q1 方法论`  
**避免：** `网站改版` / `WebsiteRedesign` / `网站_改版` 并存——过滤与统计会碎成多个「项目」。

可在库内维护一份专题索引笔记，方便统一命名。

## 3. 创建时带上可回跳的定位

- Markdown：先有块 ID，再添加  
- PDF：PDF++ 选区链接  
- Canvas：带 `nodeId` 的链接  
- EPUB：阅读器选区或定位链接（需 EPUB Reader）  

「只有书名、没有位置」的阅读点也能入队，但续读体验会差一截。

## 4. 尊重负载，而不是清空意志力

- 看月历热力与当日「合理负载 / 心流上限 / 已安排」  
- 新材料不要默认全部钉在今天  
- 逾期用改期、搁置恢复或整理积压处理  

订阅入库时分清 **添加到今天** 与 **按算法正常调度**。

## 5. 长文用连续阅读，而不是靠翻列表

同一来源拆成多点后，开启 **连续阅读**，按来源展开下一块。

## 6. 免费闭环先跑通，再开高级

先保证：添加 → 今日打开 → 回跳 → 标记进度。  
再按需激活：PDF/EPUB 导入、订阅、计时器、统计、关联笔记、深度调度等。

## 7. 不要依赖尚未稳定的能力

- **标签组**：仍在完善中，勿作主流程  
- **段落工作台**：实验中，勿替代日历  
- **FSRS**：属于 Weave Review，勿当作本插件调度说明  

## 8. 按目标组合 Weave 插件

- 只排队阅读 → 仅本插件  
- 要 EPUB 章节回跳 → + EPUB Reader  
- 要制卡复习 → + 主插件  

详见 [Weave 系列](weave-family.md)。

## 9. 备份数据根

同步与备份请包含 `weave Incremental reading/`（或你自定义的数据根）下全部 `.irdeck`。设置改路径前先确认旧数据就绪。

## 10. 归档要有意识

归档会结束活跃调度；Markdown 源可能写入归档标签便于库内筛选。重要材料归档前确认不再需要出现在日历上。
