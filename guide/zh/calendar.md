# 增量阅读日历

增量阅读日历是本插件的**主界面**：按日期查看待处理、已排期与逾期的阅读点，并用月历热力感知负载。

## 日历是什么？

日历不是「又一个笔记列表」，而是阅读点的**日程投影**：

- **上方**：月历热力——哪几天挤、哪几天空  
- **下方**：选中日期的**阅读材料**列表——当天真正要处理的队列  
- **顶部工具栏**：添加、搜索、继续阅读建议、教程、更多  

打开方式：

1. 左侧功能区的日历图标  
2. 命令面板 → **打开增量阅读日历**  

也可打开某个 `.irdeck` 专题文件，在专题视图与日历之间切换。

## 为什么用日历？

**按日推进，而不是按收藏堆。**  
链接进了稍后读文件夹，很容易只进不出。日历强迫你回答：今天读哪几条、逾期怎么办、明天负载是否过重。

**专题过滤不丢全局感。**  
月历标题旁的**专题名（chip）**可点击：在「全部」与某一专题之间切换。

**续读在原文，决策在日历。**  
列表打开条目 → 回跳来源 → 标记进度 → 由调度安排下次出现。

## 日常循环

1. 打开日历，确认今天（或要处理的日期）  
2. 查看当日列表：优先逾期与高优先级  
3. 打开阅读点，在原文续读  
4. 完成后标记进度（或暂停 / 改期 / 归档）  
5. 需要新材料时用顶部 **「+」/ 添加链接**；整书拆分用 **更多 → 导入阅读材料**  

## 界面分区

### 顶部工具栏

| 控件 | 作用 |
|------|------|
| **+ / 添加链接** | 单条创建阅读点（日常主入口） |
| 搜索 | 在材料中查找 |
| 继续阅读建议 | 额外建议项；含**已搁置**可恢复到今天 |
| 帮助 / 教程 | 插件内短教程 |
| 更多 | 导入材料、更新订阅文件夹、数据管理、视图模式等 |

### 月历区

- 点日期切换下方队列  
- 热力反映当日负载（与时间预算、心流 stretch 等相关）  
- **专题 chip**：全部 / 指定专题  

### 当日阅读材料列表

- 打开、排期、优先级、暂停、归档等  
- 右键 / 长按 → 更多操作（连续阅读、关联笔记等）  
- 可按偏好显示类型标签、计时器、缺失来源提示等（部分为高级或列表偏好）  

历史日期上的队列通常偏只读浏览；以实际 UI 提示为准。

## 连续阅读

适合同一文档被拆成多个阅读点时，按来源连续推进，而不是在列表里到处找下一块。

1. 阅读点右键 / 长按 → **更多操作** → **连续阅读**  
2. 开启后，项旁出现展开按钮，可展开同一来源下的其它阅读点  

该能力属于基础调度辅助，**无需高级授权**。

## 继续阅读建议与搁置

**继续阅读建议**用于补充「今日列表之外」仍值得推进的项，并集中处理**已搁置**材料。

- 菜单文案常见为 **暂停**；建议面板中常见为 **已搁置**——指同一类「先放下、稍后再拉回」的状态  
- 可将搁置项**恢复到今天**，重新进入当日队列  

## 与添加、导入的关系

| 方式 | 适合 | 不适合 |
|------|------|--------|
| **添加链接** | 一条 URL、双链/块、PDF++、Canvas 节点 | 一次拆完 30 章 EPUB |
| **导入阅读材料** | 整份 MD / PDF·EPUB 目录批量生成 | 每天随手记一条网页 |

## 免费与高级（日历相关）

日历与 Markdown 阅读点主流程**免费**。常见需激活的能力包括：

- 阅读计时器、统计分析  
- PDF / EPUB 章节导入、订阅文件夹  
- 关联笔记、调度策略深度自定义等  

未激活不影响「打开日历 → 读今日 Markdown 点 → 回跳续读」。

## 最佳实践

1. 每天先打开日历，再进原文  
2. 一个长期计划对应一个稳定专题名  
3. 负载偏高时用改期、整理积压或调低新材料入库速度，而不是无视热力  
4. 长文多点时开启连续阅读  
5. 不要把实验性段落工作台当作日历的替代品
