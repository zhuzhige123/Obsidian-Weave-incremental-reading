# 设置

打开方式：**设置 → Weave Incremental Reading**（独立设置面板）。

面板常见分页：**通用**、**调度**、**标签组**、**授权**、**关于**。标签组页及部分调度选项可能受授权影响；可在通用页开启 **高级功能预览**，以带锁形式查看未激活能力。

## 通用

常见项包括：

| 区域 | 内容 |
|------|------|
| 界面与阅读偏好 | 界面语言、高级功能预览、Markdown 聚焦阅读 |
| **新增阅读点默认设置** | 默认收件箱专题、Vault 链接是否默认创建阅读笔记 |
| **段落随机漫游范围** | 段落漫游的包含 / 排除文件夹 |
| **订阅剪藏文件夹** | 订阅规则（高级） |
| 数据文件夹 | 插件在 Vault 内的数据根与阅读点默认保存位置 |

更改数据根路径前，请确认旧目录内容已备份就绪。详见 [数据与维护](data-and-maintenance.md)。

## 调度

面向日常节奏与负荷控制，开关类在前、细调参数在后，例如：

- **负载与顺延**（高级）：超载缓冲、负载自动顺延、跨日平滑、单日出现上限  

- **交错学习**（高级）  
- **负荷回拉与后推**：沉底回拉、自动后推、优先级半衰期  
- **调度参数**：每日时间预算、每日阅读点上限、提前阅读窗口、间隔相关选项等  

负载与顺延、交错学习等属于高级功能——以面板锁定提示为准。概念说明见 [调度与进度](scheduling.md)。

## 标签组

常见包括：

- **标签同步**（免费）：Markdown frontmatter 标签字段（如 `weave_tags` / `tags`）  
- **标签组管理**（高级；**仍在完善中**，请勿当作当前版本日常主流程）  

未激活时仍可改标签同步；开启高级功能预览后会显示锁定的标签组入口。  

Obsidian 全局设置搜索可打开本插件设置，并尽量跳到对应分页（通用 / 调度 / 标签组等）。

## 授权

- 查看激活状态、设备与有效期等信息（以实际卡片为准）  
- 独立输入激活信息  
- 若已激活 **Weave 主插件**，本插件可**继承授权**，无需重复激活  

购买与激活以设置页说明与官方渠道为准。

## 关于

版本信息、格式说明、打开教程、官网 / 更新日志 / 社区入口等。

## 日历内偏好（不一定在设置页）

部分显示选项在日历 **更多** 或列表偏好中，例如：

- 连续阅读相关、自动开始下一个计时器  
- 调度预览、日历视图模式（完整 / 双行 / 单行等）  
- 是否显示计时器、类型标签、缺失来源  
- 是否隐藏已完成 / 已归档  

以你安装版本的菜单为准。
