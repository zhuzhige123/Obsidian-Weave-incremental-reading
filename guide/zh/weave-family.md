# Weave 系列

Weave 是一组面向 Obsidian 的知识工作流插件，围绕 **读 → 记 → 排 → 复习** 组织长期学习。系列**有且仅有三款**插件，职责分离、可组合；本插件**不依赖**主插件即可单独使用。

## 三者分工

| 插件 | 主要职责 |
|------|----------|
| **Weave Incremental Reading**（本插件） | 阅读点、专题、日历调度、续读与来源回跳 |
| **Weave 主插件（Deck）** | 记忆牌组、题库、摘录制卡、FSRS 复习等 |
| **Weave EPUB Reader** | 库内 EPUB 阅读、摘录与章节定位 |

### Weave Incremental Reading

解决「收藏很多、同时开很多本书却都读不深」：用月历推进阅读点，而不是只靠意志力。

核心能力：阅读点与 `.irdeck` 专题、增量阅读日历与连续阅读、统一添加链接、材料导入与订阅、多来源回跳等。

### Weave 主插件

基于 Obsidian 的知识卡片系统：从库内任意来源段落生成带溯源链接的记忆卡片，多视图管理，并以 FSRS 等做间隔复习。

与本插件：可**共享授权继承**；职责上是「记住与复习」，不是「阅读队列日历」。

### Weave EPUB Reader

在 Vault 内打开 EPUB 等书籍，边读边摘录；通过深链接把书中位置与笔记、增量阅读点连在一起。

与本插件：

- EPUB 章节可导入为阅读点（高级）  
- 阅读器选中文本可创建带定位的阅读点  
- 从日历回跳时打开阅读器并定位到原文  

## 怎么组合

| 目标 | 安装 |
|------|------|
| 只做增量阅读队列 | 仅本插件 |
| 还要读 EPUB 并回跳章节 | 本插件 + Weave EPUB Reader |
| 还要制卡与复习 | 本插件 + Weave 主插件 |
| 完整闭环（读 → 记 → 排 → 复习） | 三款都装 |

## 系列外协作

**PDF++**：用于 PDF 选区 / 定位链接，再通过「添加链接」或导入纳入队列。它不是 Weave 系列成员，但与 PDF 续读体验密切相关。
