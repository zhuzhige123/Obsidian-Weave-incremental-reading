# 材料导入与订阅

当你要把**整份** Markdown、PDF 目录或 EPUB 目录变成大量阅读点时，使用 **导入阅读材料**。  
当你希望某个剪藏 / 收件箱文件夹**持续自动补齐**到专题时，使用 **订阅文件夹**（高级功能）。

二者都不同于日常的 [添加阅读点](add-reading-points.md)：添加是「一条」；导入与订阅是「一批 / 持续」。

## 何时用导入

| 适合导入 | 更适合「添加链接」 |
|----------|-------------------|
| 一篇长文按标题拆成多段 | 今天看到的一篇网页 |
| 一本书按目录勾选章节 | 一个 Canvas 节点、一个 PDF++ 选区 |
| 需要预览后再批量确认 | 临时一条双链 / 块引用 |

**入口：** 增量阅读日历顶部 **「更多」→ 导入阅读材料**。

## 导入步骤

1. **选择文件**（同批只能是同一类：`md` / `pdf` / `epub`，不可混合同批）  
2. PDF / EPUB 会先进入 **目录（outline）** 步骤，勾选要导入的章节  
3. 选择拆分模式并配置参数  
4. **预览**生成的阅读点后确认导入  

导入结果写入所选专题，并按你选择的初次排期方式进入日历队列。

## 格式与能力边界

### Markdown（免费）

- 可按标题、空行等规则拆分  
- 整文件模式可选择 **引用** 或 **复制**  
- 兼容导入目录默认为「插件数据文件夹 / `IR`」（历史兼容路径；日常不必手工往里塞文件）

### PDF / EPUB（高级功能）

- 按目录生成**书签式**阅读点，保留章节续读信息  
- EPUB 目录解析依赖 **Weave EPUB Reader**  
- 未激活高级功能时，入口可能隐藏或显示为带锁预览  

外部协作：精确 PDF 选区定位建议配合 **PDF++**（非 Weave 系列）。详见 [来源与续读](source-and-resume.md)。

## 订阅文件夹（高级功能）

订阅适合「剪藏 / 收件箱」场景：指定 Vault 中的 **Markdown** 文件夹后，插件扫描并自动把符合条件的新材料补齐到绑定专题，再按规则进入增量阅读队列。

**与导入的关键区别：**

- **导入**：你主动选文件、拆分、确认——一次性  
- **订阅**：持续监听文件夹并自动补齐——持续性  

### 配置与同步

1. **设置 → Weave Incremental Reading → 基础 → 订阅剪藏文件夹**  
   - 添加规则、选择文件夹、绑定专题  
   - 配置初次排期方式、批量确认频率等  
2. **手动同步：** 日历 **更多 → 更新订阅文件夹**，或命令 **更新订阅文件夹**  
3. 插件启动或相关文件变更时，也会在后台自动同步  

### 初次排期方式（重要）

| 方式 | 含义 |
|------|------|
| **添加到今天** | 新材料钉在今天（不会按视野天数摊到后面） |
| **按算法正常调度** | 按调度视野与负载规则安排 due |

选错会导致「明明想今天读，却被摊到后面几天」或反过来把今天撑爆——配置时看清选项说明。

### 边界

- 订阅面向 **Markdown** 材料；不要假设图片或其它二进制会进入阅读队列  
- 订阅文件夹为高级功能；未激活时入口可能隐藏或带锁  

## 最佳实践

1. **同一本书用导入一次规划目录**，日常补充段落用「添加链接」  
2. **剪藏文件夹只订一个收件箱专题**，定期把重要内容挪到正式专题，避免收件箱变成永久堆积  
3. **导入前先预览**：拆分过细会抬高日上限压力；过粗则单点过长  
4. EPUB 工作流同时安装 **Weave EPUB Reader**，否则目录与回跳不完整
