# Weave Incremental Reading Docs

**Turn “read later” into a reading queue you can schedule and resume.**

These pages describe what the current standalone plugin actually does. The daily path is: **open the incremental reading calendar → capture with Add link → resume at the source → let scheduling bring items back**.

## Five-minute start

1. Install and enable **Weave Incremental Reading** (Obsidian ≥ 1.8.7)
2. Open the **incremental reading calendar** (ribbon calendar icon, or command **Open incremental reading calendar**)
3. Click **“+” / Add link**: paste source → name → topic → first day → save
4. Open today’s item, resume at the source, mark progress; scheduling picks the next appearance

See [Add reading points](add-reading-points.md) and [Calendar](calendar.md) for detail.
