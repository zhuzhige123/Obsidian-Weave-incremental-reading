# Settings

Open **Settings → Weave Incremental Reading**.

Typical tabs: **General**, **Scheduling**, **Tag groups**, **License**, **About**. Some Tag groups / Scheduling options are license-gated. Enable **Show advanced feature preview** on General to see locked entries.

## General

| Area | Content |
|------|---------|
| Interface & reading preferences | Language, advanced feature preview, Markdown focused reading |
| **New reading point defaults** | Default inbox topic; whether vault links create reading notes |
| **Paragraph random-roam scope** | Include / exclude folders for paragraph roam |
| **Subscribe clipping folders** | Subscription rules (premium) |
| Data folder | Vault data root and default Markdown reading-point folder |

Back up before changing the data root. See [Data and maintenance](data-and-maintenance.md).

## Scheduling

Toggle-first, fine-tuning last:

- **Load & deferral** (premium): overload buffer, auto defer, cross-day smoothing, daily appearance cap  

- **Interleaving** (premium)  
- **Load resurfacing & defer:** bury/pull-back, auto postpone, priority half-life  
- **Scheduling parameters:** daily time budget, daily reading-point cap, ahead window, interval options, …  

Load & deferral and interleaving may be premium—follow lock hints. Concepts: [Scheduling](scheduling.md).

## Tag groups

- **Tag sync** (free): Markdown frontmatter tag field (`weave_tags` / `tags`)  
- **Tag group manager** (premium; **still being improved**—not a daily workflow)  

Tag sync stays editable without activation; enable advanced feature preview to see the locked tag-group entry.  

Obsidian’s global settings search opens this plugin and should jump to the matching tab (General / Scheduling / Tag groups, …).

## License

- Status / device info (as shown on the card)  
- Standalone activation  
- Inherit from an activated **Weave main plugin** when supported  

## About

Version, formats, tutorial, website / changelog / community links.

## Calendar preferences (not always on the Settings tabs)

Some options live under calendar **More** or list prefs: continuous reading, auto-start next timer, schedule preview, view modes, show timers/type/missing-source, hide completed/archived. Follow your installed build’s menus.
