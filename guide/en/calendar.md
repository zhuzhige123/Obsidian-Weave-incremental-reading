# Incremental reading calendar

The calendar is the plugin’s **main surface**: browse pending, scheduled, and overdue reading points by date, and read load from the month heatmap.

## What the calendar is

Not “another note list”—a **schedule projection** of reading points:

- **Top:** month heatmap — which days are heavy or empty  
- **Bottom:** **reading materials** for the selected day  
- **Toolbar:** add, search, continue-reading suggestions, tutorial, more  

Open via the ribbon calendar icon or command **Open incremental reading calendar**. You can also open a `.irdeck` and switch between topic view and calendar.

## Why use it?

**Advance by day, not by hoard.** Clip folders fill easily and empty slowly. The calendar forces today’s choices, overdue handling, and tomorrow’s load.

**Filter by topic without losing the big picture.** Click the **topic chip** next to the month title: **All** or one topic.

**Resume in the source; decide on the calendar.** Open → jump back → mark progress → scheduling picks the next appearance.

## Daily loop

1. Open the calendar on today (or the day you mean to work)  
2. Prefer overdue and high-priority items  
3. Open a point and resume in the source  
4. Mark progress (or suspend / reschedule / archive)  
5. Capture with **Add link**; bulk-split with **More → Import reading materials**  

## UI regions

### Toolbar

| Control | Role |
|---------|------|
| **+ / Add link** | Create one reading point |
| Search | Find materials |
| Continue-reading suggestions | Extra suggestions; **suspended** items can restore to today |
| Help / tutorial | In-plugin short tutorial |
| More | Import, update subscriptions, data management, view modes, … |

### Month area

- Click a day to switch the list  
- Heatmap reflects day load (time budget, flow stretch, …)  
- **Topic chip:** All / one topic  

### Day list

- Open, schedule, priority, suspend, archive  
- Context menu: continuous reading, associated notes, …  
- Optional labels for type, timers, missing source (some premium / preferences)  

Past days are often browse-oriented; follow on-screen hints.

## Continuous reading

When one source was split into many points, advance by source instead of hunting the list.

1. Context menu → **More actions** → **Continuous reading**  
2. An expand control shows siblings from the same source  

Part of basic scheduling assistance—**no premium license required**.

## Continue-reading suggestions and suspend

Suggestions surface items beyond today’s main list and collect **suspended** materials.

- Menus often say **Suspend**; the suggestions panel may say **Suspended**—same “parked for later” idea  
- Restore a suspended item **to today** when ready  

## Add vs import

| Path | Fits | Poor fit |
|------|------|----------|
| **Add link** | One URL, block, PDF++, Canvas node | Splitting a 30-chapter EPUB at once |
| **Import** | Whole MD / PDF·EPUB outlines | One casual web clip per day |

## Free vs premium (calendar-related)

Calendar + Markdown main flow is **free**. Common premium surfaces: reading timer, analytics, PDF/EPUB import, folder subscription, associated notes, deep strategy customization.

## Best practices

1. Open the calendar before diving into sources  
2. One stable topic name per long plan  
3. Reschedule or rebalance when load spikes—don’t ignore the heatmap  
4. Enable continuous reading for multi-point sources  
5. Do not replace the calendar with the experimental paragraph workbench
