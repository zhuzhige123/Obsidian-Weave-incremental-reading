# Best practices

Practical habits aligned with the current product—not a feature dump.

## 1. One primary path

| Role | Daily habit |
|------|-------------|
| Add one item | Calendar **Add link** |
| Split a book / long note | **Import reading materials** |
| Clip inbox | **Folder subscription** (premium) |
| Start the day | Open the **incremental reading calendar** |

Do not default to the experimental paragraph workbench or any removed legacy main reading view.

## 2. Stable topic names

One plan → one `.irdeck` name. Avoid parallel spellings that fragment filters (`website-redesign` vs `WebsiteRedesign`). Keep a small index note of topic names if helpful.

## 3. Capture with locators

Markdown block IDs, PDF++ selections, Canvas node IDs, EPUB location links. File-only points enqueue, but resume feels weaker.

## 4. Respect load

Watch the heatmap and day-load summary. Don’t pin every new item to today. Clear overdue with reschedule, restore-from-suspend, or rebalance. Know **Add to today** vs **Schedule normally** for subscriptions.

## 5. Continuous reading for multi-point sources

Enable **continuous reading** instead of scrolling the flat list for the next chunk.

## 6. Free loop first, premium later

Ship add → open today → resume → mark progress before unlocking PDF/EPUB import, subscription, timers, analytics, associated notes, or deep strategy knobs.

## 7. Don’t lean on unfinished surfaces

- **Tag groups** — still being improved  
- **Paragraph workbench** — experimental  
- **FSRS** — Weave Review, not this scheduler  

## 8. Combine Weave plugins by goal

Queue only / + EPUB Reader / + Deck / all three — see [Weave family](weave-family.md).

## 9. Back up the data root

Include `weave Incremental reading/` (or your custom root) and every `.irdeck`. Confirm the old folder before changing the path.

## 10. Archive deliberately

Archiving ends active scheduling; Markdown sources may receive archive-related tags. Confirm you no longer need the item on the calendar.
