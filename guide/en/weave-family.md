# Weave family

Weave is a set of Obsidian plugins around **read → capture → schedule → review**. There are **exactly three** plugins. They compose; **this plugin does not require** the main plugin.

## Division of labor

| Plugin | Responsibility |
|--------|----------------|
| **Weave Incremental Reading** (this) | Reading points, topics, calendar scheduling, resume |
| **Weave main plugin (Deck)** | Memory decks, quizzes, excerpt-to-card, FSRS review |
| **Weave EPUB Reader** | In-vault EPUB reading, excerpts, chapter location |

### Weave Incremental Reading

For “collected too much, finished too little”: advance points on a calendar instead of willpower alone.

### Weave main plugin

Traced memory cards from vault excerpts, multi-view management, FSRS study sessions. Optional **license inheritance** with this plugin. Job: remember and review—not the reading-queue calendar.

### Weave EPUB Reader

Open EPUB in the vault, excerpt while reading, deep-link locations to notes and IR points.

With this plugin: import chapters as points (premium), create located points from selections, resume from the calendar into the reader.

## How to combine

| Goal | Install |
|------|---------|
| Queue only | This plugin alone |
| Also read/resume EPUB chapters | + Weave EPUB Reader |
| Also create cards and review | + Weave main plugin |
| Full loop | All three |

## Outside the family

**PDF++** helps PDF selection/location links enter the queue via Add link or import. Not a Weave plugin, but important for precise PDF resume.
