## Документация на русском

**Weave Incremental Reading** (ID плагина: `weave-incremental-reading`) — **автономный** плагин инкрементального чтения для Obsidian.

Он помогает собрать разрозненные материалы из Markdown, блоковых ссылок, PDF (вместе с [PDF++](https://github.com/RyotaUshio/obsidian-pdf-plus)), Canvas, веб-страниц и EPUB в удобную **очередь точек чтения** с планированием, продолжением чтения и возвратом к источнику, а затем вести её через **темы** и **календарь** — чтобы контент не оставался в состоянии «сохранил и забыл».

Плагин работает самостоятельно и **не зависит** от основного плагина Weave. Другие плагины серии устанавливайте только при необходимости чтения EPUB в хранилище или создания карточек в колодах памяти.

---

### Три ключевых понятия

| Понятие | Описание |
|------|------|
| **Точка чтения** | Одна задача на чтение с привязкой к источнику; из очереди можно одним кликом вернуться к оригиналу и продолжить. |
| **Тема (IRDeck)** | Контейнер точек чтения, хранится в хранилище как файл `.irdeck`; группировка по теме или плану. |
| **Календарь инкрементального чтения** | Главный экран плагина: по датам смотрите ожидающие, запланированные и просроченные точки и задавайте ежедневный ритм. |

---

### Основные возможности

- **Календарь инкрементального чтения** — тепловая карта месяца и очередь дня; нагрузка, приоритет и просрочки; вспомогательные действия для непрерывного чтения
- **Единое «Добавить ссылку»** — вставьте веб-URL, вики-ссылку, блочную ссылку, позицию PDF++, узел Canvas, позицию EPUB; сразу задайте имя, тему и первый день чтения
- **Управление темами и точками чтения** — приоритет, пауза, архив; откройте `.irdeck` и переключайтесь между видом темы и календарём
- **Планирование и продолжение** — стратегии потока обработки / списка чтения, дневные лимиты и бюджет времени; после прогресса автоматически назначается следующее появление
- **Импорт материалов** — пакетный разбор и импорт из Markdown; в премиуме — подписка на папки, пакетный импорт глав PDF / EPUB
- **Возврат к источнику** — стабильные позиции продолжения для Markdown, PDF++, Canvas, веб-страниц и EPUB

### Быстрый старт

1. Установите и включите плагин (см. [установку](#установка-и-обновления) ниже)
2. Откройте **календарь инкрементального чтения** (иконка календаря на ленте слева или команда «Открыть календарь инкрементального чтения»)
3. Нажмите **«+» / Добавить ссылку** вверху календаря: вставьте источник → измените имя → выберите тему → назначьте первый день чтения → сохраните
4. Откройте сегодняшние пункты в календаре, продолжите чтение в источнике; отметьте прогресс — плагин назначит следующее появление

Для повседневного пути рекомендуется **Добавить ссылку**; команды по выделению и контекстное меню по-прежнему доступны.

### Установка и обновления

#### Установка из Release (сейчас рекомендуется)

1. Откройте [Releases](https://github.com/zhuzhige123/Obsidian-Weave-incremental-reading/releases) этого репозитория и скачайте вложения последней версии
2. Создайте в хранилище каталог:

   ```text
   .obsidian/plugins/weave-incremental-reading/
   ```

3. Поместите в него `main.js`, `manifest.json` и `styles.css` из **того же** Release
4. Включите **Weave Incremental Reading** в **Настройки → Сторонние плагины**

#### Отслеживание версий через BRAT

Если используете [BRAT](https://github.com/TfTHacker/obsidian42-brat), добавьте этот репозиторий и выберите **Weave Incremental Reading** для проверки обновлений.

#### Каталог сообщества Obsidian

Если плагин уже есть в каталоге сообщества, ищите **Weave Incremental Reading** в **Настройки → Сторонние плагины**.

#### Системные требования

| Параметр | Требование |
|------|------|
| Obsidian | **≥ 1.8.7** (см. `minAppVersion` в `manifest.json`) |
| Платформы | Десктоп и мобильные |

### Связь с серией Weave

Weave — набор плагинов для рабочих процессов знаний в Obsidian, построенных вокруг **читать → записывать → планировать → повторять**. Этот плагин отвечает за **очередь инкрементального чтения и календарное планирование**; остальные участники дополняют его и могут комбинироваться.

| Плагин | Основная роль |
|------|----------|
| **Weave Incremental Reading** (этот плагин) | Точки чтения, темы, календарное планирование, продолжение и возврат к источнику |
| **Основной плагин Weave** | Колоды памяти, банки вопросов, карточки из выдержек, повторение FSRS и др. |
| **Weave EPUB Reader** | Чтение EPUB в хранилище, выдержки и позиционирование по главам |

Как комбинировать:

- **Только очередь инкрементального чтения** — достаточно этого плагина
- **Также читать EPUB и возвращаться к главам** — этот плагин + Weave EPUB Reader
- **Также карточки и повторение** — этот плагин + основной плагин Weave
- **Полный цикл (читать → записывать → планировать → повторять)** — все три

Внешняя совместная работа (не серия Weave): **PDF++** для ссылок на выделение/позицию в PDF через «Добавить ссылку».

### Бесплатные и премиум-функции

Текущая версия: **календарь и основной поток точек чтения Markdown бесплатны** — этого достаточно для повседневного инкрементального чтения.

| Бесплатно | Премиум (нужна активация) |
|------|----------------|
| Календарь и точки чтения Markdown | Пакетный импорт точек чтения глав PDF / EPUB |
| Управление темами и точками (приоритет, пауза, архив) | Настройка стратегий планирования, interleaved learning |
| Базовое планирование, очередь на сегодня, возврат к чтению | Автосинхронизация подписки на папки |
| Создание точек через «Добавить ссылку» (MD, блочные ссылки, PDF++ и др.) | Аналитика, таймер чтения, фон календаря и др. |
| Разбор/импорт из Markdown, инструменты управления данными | Связанные заметки для точек чтения и другие возможности |

Без активации премиум-входы явно помечены; базовый поток чтения не затрагивается.

Если установлен и активирован **основной плагин Weave**, этот плагин может унаследовать его лицензию без повторной активации. Самостоятельная активация: **Настройки → Weave Incremental Reading → Лицензия**.

---

### Данные и конфиденциальность

- Точки чтения, темы, расписания и настройки **по умолчанию хранятся в локальном хранилище**
- Плагин **не загружает** содержимое ваших заметок по своей инициативе
- Межплагинное взаимодействие (возврат EPUB, проверка лицензии и т.п.) происходит только при реальном использовании соответствующих функций
- Удаление плагина **не удаляет автоматически** созданные `.irdeck` и данные точек чтения; очищайте через инструмент управления данными или вручную
